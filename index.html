02 Featured Projects

HITMISSHITHIT

RISC-V Memory Hierarchy Simulator

Purpose: explore how cache configurations and replacement policies affect memory access performance.

Built: a trace-driven Python cache simulator supporting direct-mapped, set-associative and fully associative caches with LRU and FIFO. Reports hits, misses, hit/miss rate and AMAT, and generates performance graphs.

My contribution: modular design (cache management, replacement policies, simulation, trace parsing); LRU and FIFO; a synthetic trace generator (sequential, strided, random, matrix-style); automated parameter sweeps with graphs.

Python · NumPy · Matplotlib · Git

GitHub

TRAFFIC/PATTERN.DASH

Purpose: find peak traffic hours, the busiest weekday and hour-by-weekday patterns in web server logs.

Built: a static, 100% client-side dashboard for Apache/NASA-format access logs, with no backend, database or server cost. KPI row, requests per hour and per weekday, a 7×24 heatmap with tooltips, top paths and an HTTP status breakdown.

Demo hosted on Cloudflare Pages.

Live demoGitHub
MalabarKochiTravancore

The Lost Memories of Maveli

Purpose: an Onam-inspired adventure (about 5–7 minutes) where players recover three lost memories of King Maveli.

Built: a browser game in Phaser 3 and Vite with three levels (Malabar village, Kochi backwaters boat, Travancore palace puzzle) and an ending with Maveli. All art, sound and UI are generated at runtime with Phaser Graphics and Web Audio, with no external image or audio files.

First Prize, ONAM.exe. Pixel-art; best experienced on a laptop or desktop.

Phaser 3 · Vite · JavaScript · Web Audio
